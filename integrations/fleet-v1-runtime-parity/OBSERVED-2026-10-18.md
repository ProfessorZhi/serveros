## 关键发现

### 1. Codex 实际在线且可读，但 Tokyo registry 未绑定它

- `agent_provider_list` 返回 `provider:codex-app-server`：control plane `RUNNING`
  （`codex:initialize`），`agent_list` 与 `agent_session_list` 均
  `READ_AUTHORIZED`；2 个既有 Codex session 的 `model` 字段由
  `codex:thread/list` 以 `FACT` provenance 返回。
- 但 `device_list` / `device_inspect` 的 `agent_runtimes.bindings` **只有**
  `agent-runtime:claude-code`，`declared_agents` 也只有 `claude-code`。
- 因此：Codex 是 **observed but unbound**。读取 metadata 不等于新的
  create/send/resume/interrupt 授权；投影对四个 new-work verb 全部
  `REFUSED` + `PROVIDER_UNBOUND`，**不 fallback** 到 claude-code 或另一个账号。

这是本轮最重要的 observed-vs-declared 差异，也是下一步需要 owner/F1 决策的
authoring 问题（不在 R1 的写入范围内）。

### 2. Claude Code 只有 CLI 与 BotMux 间接会话，没有直接 provider

- `claude` CLI 安装且版本为 `2.1.272 (Claude Code)`；binding `BOUND`；
  instruction/MCP surfaces 由 `serverosctl device agents --probe` 观测为
  `AVAILABLE`。
- provider inventory 中**没有** `provider:claude-code`；唯一的 Claude Code
  会话路径是 `provider:botmux-agent-session`（dashboard adapter）。
- BotMux 的控制面可达（`botmux:/api/sessions`），session metadata 可读：
  1 个既有 session，`status=IDLE` 且 provenance 为 **INFERRED**（BotMux 从 CLI
  屏幕内容推导），`can_accept_input=true` 是 provider-reported capability，
  **不是 grant**。
- 但 agent inventory 读取返回 `NEEDS_LOGIN`：BotMux dashboard 认证缺失。
  没有读取、复制或注入任何 credential/token。
- 既有 session 可读**不构成**新的 CC 账号 entitlement；effective model 与
  permissionMode 均未被 provider metadata 证明，保持 `UNKNOWN`。

### 3. Codex 的 effective model 是真实 readback，permissionMode 不是

- `gpt-6-astra` 来自 `codex:thread/list`，每个 session 的
  `provider_evidence.provenance = FACT`、`authoritative = true`。
  这证明的是**该 thread 配置的模型**，不是 license/账号 entitlement 声明。
- `permissionMode` 在已授权的 session metadata 中不存在；`sandbox` /
  `approvalPolicy` 是配置项，不能当作 effective mode。故为 `UNKNOWN`。
- 没有读取 transcript/turn 内容，因此不声称任何 turn 结果或模型调用。

### 4. `CONFORMANT` 是结构性结论，不是 LIVE

`serverosctl device agents --probe --json` 返回 `verdict: CONFORMANT`，其 scope
明确写着：只覆盖 declared ids、adapter surfaces 与 presence，**行为性 session
smoke 不在其中**。本轮 `behavioral.state = NOT_RUN`，`live = false`。
