### Synthetic-Windows probe caveat

The probe is a **collection-precondition simulation**, not a Windows run. It
sets `os.name == "nt"` and blocks only `fcntl`; `pytest`/`pathlib` keep the
real POSIX `os`. Per-file execution is required: running several files in one
process lets a partially initialized `sys.modules["serveros_runtime_daemon"]`
cache the first error and falsely report later files as `COLLECTED`. The
3 ERROR / 3 SKIPPED receipts above are per-file.
