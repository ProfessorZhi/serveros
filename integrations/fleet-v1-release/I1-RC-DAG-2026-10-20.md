Semantic edges and forced order:

1. **#298 → #272.** The adapter's production protocol and its canonical
   resource function live on #272. Details in §5. #298 must not land before
   #272; a checkout without the #272 object skips its cross-repo test.
2. **#295 ↔ #275.** Both implement the T6 expired-lease reader in
   `context/resolver.py`. They are not independent fixes; landing both is a
   textual conflict and leaves two definitions of the same boundary. One owner
   must own the change (§4).
3. **S1 send admission → a legitimate lease producer.** #261 makes the send gate
   read the Work Engine lease. The WE stack (#296/#298) supplies fail-closed
   authority seams, but no OS-principal + grant verified parent is bound to a
   session-create path. The join is still `BLOCKED_PRODUCER_BOUNDARY`.
4. **T10 strict acceptance → the #269 runtime.** #277 consumes the
   `RunnerReceiptAuthority` runtime introduced by #269; the chain is
   fast-forward. WE finalize/continuation consumption remains `BLOCKED_WIRING`.
5. **#255 → #243.** G1 is a child of F1; any F1 re-base changes G1's base and
   forces a G1 re-pin.
6. **#243 → #231 → a non-PR base branch.** `stack/fleet-v1-pre-core-lite-wiring`
   is a branch, not a PR head. #243 cannot be merged into `main` as-is; its
   owner must retarget/re-base it.
7. **#230 is a sibling of #243, not a child.** Their own-commit file surfaces
   are disjoint; the shared files are inherited ancestry, not collision.
8. **#233/#239 consume F1's Core readback.** M1 cannot be accepted before the
   F1 readback contract is accepted.
9. **The external `ProfessorZhi/work-engine` repository is archived.** Its
   #13–#16 are closed unmerged; #295–#298 are the source-level ports into the
   consolidated `serveros` tree. The release manifest must pin the in-tree
   `workengine/` at the WE stack tip, not the archived repository.

  "fc93590030c218934252920a53aa67277f144844")` — the default is the **#272

  newline-JSON over AF_UNIX to `agent.lease.authority.verify`. That method is
  added by #272 (`runtime/daemon.py` / `runtime/agent_control_store.py`); it is
  not on `main`.
- `tests/test_serveros_lease_authority.py:331`: asserts
  `resolver.work_write_resource(ITEM) == RESOURCE`, where `resolver` is loaded
  from the materialized #272 tree. The canonical resource derivation is also a
  #272 artifact (`context/resolver.py`).
- `docs/serveros-lease-authority.md:7,120` records the same pin and the
  `BLOCKED_TRUST_SOURCE` production status.

Consequences:

1. Land #272 (via the S1 chain, at least through #275) before #298.
2. After #275 lands, #272's commit is in `main` history and the default
