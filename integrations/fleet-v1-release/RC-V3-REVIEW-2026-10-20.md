## 3. T10 → Finalize `ReceiptError` identity contamination (located)

Same-process combined run (T10 five files + finalize/receipt three files +
core boundary): **55 failed, 75 passed**. The root cause is located:

- `tests/test_fleet_v1_t10_authority_bridge.py:121-128`
- `tests/test_fleet_v1_t10_signed_finalization.py:127-134`

Both do:

```python
sys.path.insert(0, str(src))
for name in [n for n in sys.modules if n == "workengine" or n.startswith("workengine.")]:
    del sys.modules[name]
import workengine                      # from the archive on sys.path
from workengine.authority import ReceiptError, ...
```

They evict and replace `sys.modules["workengine"]` with the archived package and
do not restore it. The later finalize/receipt tests import a different
`workengine.authority.ReceiptError` class, so their `assertRaises(ReceiptError)`
does not catch the exception raised by the in-tree store.
