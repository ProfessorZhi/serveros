### 1.1 Static safety review

- `make_directory_symlink_or_skip` catches `OSError`, and calls
  `symlink_privilege_reason`; **only** `os.name == "nt"` and
  `exc.winerror == 1314` become `pytest.skip("HOST_PRIVILEGE_NO_SYMLINK")`.
  Every other error re-raises and stays a failure — no blanket skip. Synthetic
  tests cover the negative (1314 on POSIX, other WinError, non-privilege
  errors).
- `_must_refuse` now refuses drive-relative paths (`D:relative\path`), 8.3 short
  names (`OWNER~1`) and components with a trailing space/dot, rather than
  assuming "outside". This is a conservative refusal, not a new trust grant.
- The README explicitly records the residual limits: no `GetLongPathName`, no
  per-drive CWD, no real NTFS mapping; the guard is a check-time test aid, **not
  an OS sandbox**. The 13 grant-suite and 19 legacy skips remain explicit
  platform skips; a skip is not a pass.
- No authority, grant, daemon, provider or production code is changed.
