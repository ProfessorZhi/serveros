## 5. Blockers and not-run

RC-v8 is **not release-ready**:

1. **X2 synthetic Windows gate has a red default environment** (import path
   coupling). It passes with `tests` on `PYTHONPATH`, but the documented
   `PYTHONPATH=<rc>` run fails. A test-only harness correction or an author
   import change is required before this gate is green under its documented
   command.
2. **QA2 raw harness taxonomy drift**: R1 findings expects `REFUSED_REPLAY`,
   while #361 returns the stronger `BLOCKED_PROVIDER_SOURCE` with
   `settle_allowed=false`; R1 controls probe cannot read the new shape. The
   adapted QA AG r17 probe is 25/25, but the original harness does not pass
   as-is.
3. **S1 controls are 34/36**, not 36/36: two positive controls now correctly
   receive `BLOCKED_OWNER_COMMIT_SEAM`. This is the intended fail-closed
   behavior, but it is a behavior change requiring reviewer acceptance.
4. **No production `COMMIT_FENCED` producer exists.** Owner-backed lease
   authority is `BLOCKED_OWNER_COMMIT_SEAM / NOT_V1_SIGNED`; the adapter's
   `COMMIT_FENCED` acceptance is exercised only with a synthetic answer.
5. **R1 remains synthetic-only.** No owner-signed provider source; production
   is `BLOCKED_PROVIDER_SOURCE`.
6. **No independent QA signature at the RC-v8 SHA.** QA AG is `QA_PARTIAL`.
   A unit/probe green does not waive a signature.
7. **Hosted CI is `NOT_RUN`** at this SHA. Real Windows SCM/MSVC,
   `REAL_DEVICE`, `CLIENT_E2E`, OAuth and T1–T12 remain `NOT_RUN` or `BLOCKED`.
8. **The docs commit is after the tested tip.** Its SHA is reported in the
